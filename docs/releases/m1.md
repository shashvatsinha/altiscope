## Changes

- Overall v3 code review with PR provenance and unverified interpretation (#11).
- Tight quotes, unique hexadecimal commit prefixes, real hunk headers, compound comment identity (#12).

- Reproducible offline/persisted fixture, reviewed sample, walkthrough and regression set (#17).
